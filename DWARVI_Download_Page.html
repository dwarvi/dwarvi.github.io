How to install

  1. Tap Download APK above and download the file from the DWARVI GitHub Releases page.
  2. Open the downloaded DWARVI-release.apk file.
  3. If Android asks, allow your browser or file manager to install apps from this source. The setting may be called Install unknown apps.
  4. Return to the installer and tap Install.
  5. When installation finishes, open DWARVI Calculator.
Safety note: Install APK files only when you trust the publisher. Android may show a security warning because this app is installed outside Google Play. Never disable Play Protect globally just to install an APK.
